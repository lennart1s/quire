4Print

Check both sheets, then print or save them as a PDF.

  • In the print dialog set scale to 100 % / Actual size, margins to None and turn headers and footers off.
  • To get a PDF, choose “Save as PDF” as the destination.
  • Printing both sides: flip on the long edge. The pattern is centered, so front and back line up.
  • “Everything in one PDF” with an A3 cover mixes paper sizes. That works in Chrome and Edge; for printing directly, print separately.
